Host: Linux x86_64 with rootless Podman or Docker, Bash, tar, and standard Unix utilities.
Run podman info or docker info as your normal user. CONTAINER_ENGINE selects an
engine explicitly; Podman is preferred when both are installed. The container
provides Rust 1.97.1, Qt 6.10.3, CMake 3.31.6, Python and native dependencies.
Output: dist/cords-client-linux-x86_64-<version>.tar.gz and .sha256.
Use CORDS_BUILD_CACHE_DIR, CARGO_TARGET_DIR, CORDS_QT_BUILD_DIR, CORDS_DIST_DIR
for persistent cache and output overrides. See build-scripts/README.md.
