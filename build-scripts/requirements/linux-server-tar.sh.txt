Host: Linux x86_64 or ARM64 with rootless Podman or Docker, Bash, tar, and standard Unix utilities.
Run podman info or docker info as your normal user. The container provides
Rust 1.97.1 and all server build dependencies. Output: dist/cords-server-linux-<arch>-<version>.tar.gz and .sha256.
Use CONTAINER_ENGINE to select an engine and CORDS_DIST_DIR, CARGO_TARGET_DIR,
CORDS_BUILD_CACHE_DIR to override persistent output/cache paths.
