Host: macOS Intel/Apple Silicon; output: universal Qt application DMG.
Tools: Bash, Rust/Cargo 1.97.1 and rustup, Python 3, CMake >=3.24,
Xcode C++17 compiler and macOS SDK, make or Ninja, codesign, hdiutil, lipo,
file, find, grep, ln, standard Unix utilities, sha256sum or shasum.
Rust targets: aarch64-apple-darwin AND x86_64-apple-darwin.
SDK: universal Qt 6.10.3, both arm64 and x86_64 slices, with Core, Gui,
Network, Qml, Quick, QuickControls2, Widgets, Concurrent, Test and QuickTest.
Xcode must be selected, initialized and its license reviewed/accepted.

Setup (run explicitly; this script does not install packages):
  xcode-select --install
  xcrun --find clang++
  export PATH="$HOME/.cargo/bin:$PATH"
  rustup toolchain install 1.97.1
  rustup target add --toolchain 1.97.1 aarch64-apple-darwin x86_64-apple-darwin
  python3 -m venv "$HOME/.local/share/cords-build-tools"
  "$HOME/.local/share/cords-build-tools/bin/python" -m pip install cmake aqtinstall==3.3.0
  export PATH="$HOME/.local/share/cords-build-tools/bin:$PATH"
  aqt install-qt mac desktop 6.10.3 clang_64 --outputdir "$HOME/Qt" --archives qtbase qtdeclarative qtsvg qttools qttranslations
  export CORDS_QT_PREFIX="$HOME/Qt/6.10.3/macos"
QT_ROOT_DIR is also accepted. Verify both Qt slices with lipo -info before use.
Use xcodebuild -license to review an outstanding Xcode license; accept it yourself
with the permissions required by your Mac. Ad hoc app signing is the default.
